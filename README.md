# 시너지 미적분1 오답노트 & 손풀이 허브

노션(Notion)의 **시너지 미적분1 DB**와 연동하여, 문제 번호 또는 범위를 입력하면 **오답노트 스타일 문항 리스트**와 **초강조 손풀이 영상**을 한눈에 확인할 수 있는 웹 서비스입니다.

---

## 🌟 주요 기능

1. **오답노트 스타일 번호 & 범위 검색**
   - **단일 번호 검색**: `123`, `0121`
   - **다중 번호 검색**: `1, 3, 5, 22, 121, 123`
   - **범위 검색 (`-` 또는 `~`)**: `120-124`, `1~15`, `904-940`
   - **복합 검색**: `1-5, 22, 120~124`

2. **지정된 6대 핵심 항목 표시**
   - **문제번호**: `# 0123` 하이라이트 뱃지
   - **단원**: 예) `1. 함수의 극한`
   - **난이도**: `상`, `중`, `하` 색상 뱃지
   - **손풀이링크**:
     - 🎬 손풀이 영상 보기 (새 탭) ↗ 버튼
     - 📋 원클릭 `복사` 버튼
     - ▶ 16:9 내장 유튜브 플레이어 (타임스탬프 자동 연동)
   - **문제유형**: 예) `접선의 개수와 함수의 연속성`
   - **출제의도**: 깔끔한 행 표시 (KaTeX 수식 자동 렌더링)

3. **오답노트 전용 편의 도구**
   - **빠른 선택 칩**: `120~124번`, `22~38번`, `904~940번`, `손풀이 있는 문제만`, `전체 문항`
   - **단원 & 난이도 필터**: 드롭다운 및 버튼으로 즉시 세부 필터링
   - **🖨️ 오답노트 인쇄 / PDF 출력**: 불필요한 검색 UI 없이 A4 문제지/해설지 형태로 깔끔하게 인쇄

4. **노션 실시간 최신 동기화 & 자동 배포**
   - **노션_동기화하기.cmd**: 노션 DB의 최신 수정 사항을 1클릭으로 동기화하고 GitHub 및 Vercel로 자동 배포합니다.

---

## 🚀 실행 방법

### 방법 1: 온라인 웹사이트 (어디서나 접속)
배포 URL: **[https://sonpuri-hub.vercel.app/](https://sonpuri-hub.vercel.app/)**

### 방법 2: 로컬 실행
폴더 내 **`실행하기.cmd`** 파일을 더블 클릭하면 로컬 서버 구동과 웹 브라우저(`http://localhost:5000`)가 자동으로 열립니다.
